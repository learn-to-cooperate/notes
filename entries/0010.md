# `CONTRIBUTING.md`

**Date: 2026-02-10**

> Git enables collaboration technically.
> `CONTRIBUTING.md` enables collaboration socially.

## Where should it live (and why)
If your repository contains a file named one of these:

- `CONTRIBUTING.md`
- `docs/CONTRIBUTING.md`
- `.github/CONTRIBUTING.md`

then GitHub will:

- show a “Contributing” link in the repository sidebar
- display it automatically when someone opens a new issue or pull request
- sometimes shows a reminder during PR creation (“Please review the contributing guidelines”)

## What `CONTRIBUTING.md` is for

`CONTRIBUTING.md` exists to make cooperation explicit and predictable.

Its purpose is coordination: explaining how collaboration works in this project so that contributors can act with confidence.

## Why it matters for cooperation in Git projects

Git-based collaboration is asynchronous and distributed.
People contribute at different times, with different levels of experience, and often without direct communication.

`CONTRIBUTING.md` provides a shared reference point.
